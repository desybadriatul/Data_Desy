# Cogan Metric Mapping v1

Status: LOCKED

## Social media

- Registry label `Engagement` dipetakan ke `interactions`.
- `Views` selalu disimpan sebagai metric terpisah.
- `source_engagement` hanya diagnostic internal.
- Jangan menggabungkan interactions dan views.
- `Avg Engagement per Post` pada registry dipetakan menjadi:
  `avg_interactions_per_applicable_post`.

## Mainstream Media

- KPI utama: article/news count, media count, ad value, PR value,
  readership, circulation bila tersedia.
- Tidak memaksa interactions untuk Online Media, Print, TV, Radio, atau Blog.

## Semua report

- Post/article count berasal dari canonical unique-post layer.
- Channel tanpa rumus interactions tidak boleh diberi nilai nol untuk ranking.
- Metric readiness dan data health harus ikut report input package.
