Logos (transparent PNG, auto-trimmed by the engine).

Included:
  dataxet-sonar.png   — agency mark (top-left on every slide)
  le-minerale.png     — Le Minerale client logo (top-right)

To add a client:
  Drop the official transparent PNG here, named to match theme.js -> clients.<key>.logoClient
  e.g.  gopay.png   (referenced by theme.js: "assets/logos/gopay.png")
        kementan.png

Tips:
  - Use a transparent background so the logo sits cleanly on any slide tint.
  - Any size is fine; the engine trims whitespace and scales to preserve aspect ratio.
